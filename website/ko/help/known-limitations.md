# 알려진 한계

- whisper.cpp는 아직 특정 git 태그나 커밋에 고정되어 있지 않습니다.
  `brew install whisper-cpp`는 업스트림의 `stable` 버전을 그대로 따라가므로,
  이후 업그레이드에서 경고 없이 동작이 바뀔 수 있습니다.
- `diarize` 모드는 이 머신에서 실제 녹음으로 end-to-end 테스트를 아직 하지
  않았습니다. 개발 당시에는 `whisper-cli`와 모델이 설치되어 있지 않았습니다.
  코드 경로는 실제 `whispermlx` 라이브러리 소스를 읽고 수정했지만, 이 모드에
  의존하기 전에 라이브 스모크 테스트를 한 번 해 보는 것이 좋습니다.
- 서로 다른 두 녹음이 같은 카테고리와 라벨로 정해지면 전사 결과 디렉터리를
  덮어씁니다. 같은 작업을 다시 실행할 때가 아니라, 서로 다른 녹음의 파일 이름이
  실제로 겹칠 때 생기는 문제입니다. 원본 오디오는 [결과물과 아카이브](/ko/reference/output)에서 설명한
  내용 해시 접미사로 이 문제를 막지만, 전사 결과는 현재 막지 못합니다.
- `HUGGINGFACE_TOKEN`은 현재 gitignore에 등록된 plist 파일에 직접 넣어야
  합니다. macOS 키체인이나 별도 시크릿 파일에서 읽는 기능은 아직 없습니다.
- `미분류` 폴더 이름은 코드에 고정되어 있어 로케일에 따라 바뀌지 않습니다.
- 전사 언어는 현재 한국어(`ko`)로 고정되어 있습니다. 다른 언어는 아직 설정할 수 없습니다.
