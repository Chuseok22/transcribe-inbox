# 지원하는 모드

모드는 3가지입니다.

| 모드 | 언제 쓰나 | 엔진 | 화자 라벨 |
|---|---|---|---|
| `asr` (기본값) | 화자가 한 명인 녹음 (강의, 혼자 말한 메모) | whisper.cpp | 없음 |
| `asr-multitrack` | 화자별로 파일이 이미 나뉘어 있는 녹음 (참석자가 각자 자기 기기로 녹음한 회의) | whisper.cpp (트랙마다 한 번씩) | 트랙 파일 이름(확장자 제외) |
| `diarize` | 한 파일 안에 여러 화자가 섞여 있는 녹음 (마이크 하나로 녹음한 회의) | whispermlx | 화자분리 모델이 붙인 익명 라벨 |

`diarize`는 화자를 구분하고 `asr`은 구분하지 않습니다. 전사 품질은 두 모드가 같습니다. 화자를
나눌 필요가 없으면 `diarize`를 쓸 이유가 없습니다. 정렬(alignment)과 화자분리
단계가 더 돌기 때문에 시간이 상당히 더 걸립니다.

화자별 파일이 이미 있다면 `diarize`보다 `asr-multitrack`이 낫습니다.
화자분리는 추론이라 틀릴 수 있습니다. `asr-multitrack`은 어느 파일이 누구
것인지 정해져 있어서 화자 라벨이 틀리지 않습니다.

## `asr`: 단일 화자 (기본값)

모드 폴더를 생략하면 됩니다.

```
~/Transcribe/inbox/
└── 강의/
    └── 2주차.m4a
```

- 전사 결과: `~/Obsidian/second-brain/Transcripts/강의/2주차/`
- 아카이브: `~/Transcribe/archive/강의/asr/2주차.m4a`

`~/Transcribe/inbox/강의/asr/2주차.m4a`처럼 모드 폴더를 명시해도 결과는
같습니다.

## `diarize`: 여러 화자가 한 파일에 섞인 회의

```
~/Transcribe/inbox/
└── 회의/
    └── diarize/
        └── 2026-09-08.m4a
```

- 전사 결과: `~/Obsidian/second-brain/Transcripts/회의/2026-09-08/`
- 아카이브: `~/Transcribe/archive/회의/diarize/2026-09-08.m4a`
- 화자 라벨은 화자분리 모델이 붙이는 익명 라벨이며 실제 사람 이름이 아닙니다.
  누가 누구인지는 전사본을 보고 직접 맞춰야 합니다.
- `HUGGINGFACE_TOKEN`과 모델 약관 동의는 이 모드에만 필요합니다 ([사전 준비물](/ko/getting-started/prerequisites) 참고).

## `asr-multitrack`: 화자별로 파일이 나뉜 회의

모드 폴더 아래에 세션 폴더를 하나 만들고, 그 안에 화자별 파일을 넣습니다.

```
~/Transcribe/inbox/
└── 회의/
    └── asr-multitrack/
        └── 2026-09-08/
            ├── 김철수.m4a
            └── 홍길동.m4a
```

- 세션 폴더 `2026-09-08` 전체가 작업 하나입니다. 트랙마다 전사한 뒤
  시간순으로 정렬해 전사본 하나로 합칩니다.
- 화자 라벨은 파일 이름에서 확장자를 뺀 값입니다. 위 예시에서는 `김철수`,
  `홍길동`입니다. 파일 이름을 화자 이름으로 지으세요.
- 전사 결과: `~/Obsidian/second-brain/Transcripts/회의/2026-09-08/`
  (파일 이름이 아니라 세션 폴더 이름을 씁니다)
- 아카이브: `~/Transcribe/archive/회의/asr-multitrack/2026-09-08/`
  (파일을 하나씩 옮기지 않고 세션 폴더째 옮깁니다)

**주의: 세션 폴더에는 화자별 오디오 파일만 넣으세요.**

- 세션 폴더 안의 파일은 숨김 파일을 빼고 모두 트랙으로 등록됩니다. `.txt`,
  `.dat` 같은 메타데이터 파일이 섞여 있으면 그 파일도 오디오로 디코딩하려다
  실패하고, 세션 전체가 `FAILED`가 됩니다. 실패한 작업은 자동으로 재시도하지
  않습니다 ([사용법](/ko/guide/usage)의 "실패했을 때" 참고).
- 모든 트랙이 같은 시각에 시작한다고 가정합니다. 트랙별 시작 시점 보정
  (오프셋)은 지원하지 않으며, 모든 트랙을 0초부터 시작한다고 보고 시간순으로
  합칩니다. 트랙마다 녹음 시작 시점이 다르면 합친 전사본의 발언 순서가 틀어질
  수 있습니다. 화자별 파일이 같은 시점에 녹음을 시작했는지 먼저 확인하세요.
- 파일은 세션 폴더 바로 아래에만 두세요. 세션 폴더 안에 하위 폴더를 만들면
  안 됩니다 ([인박스 폴더 구조](/ko/guide/inbox-layout)의 "애매한 경로" 참고).

### 예: Discord 회의를 Craig로 녹음한 경우

Craig에서 멀티트랙으로 내려받은 폴더에는 화자별 오디오와 함께 메타데이터
파일이 들어 있습니다.

```
craig-xxxxxxxx/
├── 1-alice.aac             # 화자별 트랙 (앞에 번호가 붙음)
├── 2-bob.aac
├── 3-carol.aac
├── info.txt               # 메타데이터 — 넣으면 안 됨
└── raw.dat                # 원본 데이터 — 넣으면 안 됨
```

이 폴더를 통째로 넣지 말고, 오디오 파일만 골라 세션 폴더에 복사하세요. 화자
라벨은 파일 이름에서 나오므로 번호 접두어는 떼는 것이 좋습니다
(`1-alice.aac` → `alice.aac`).

```
~/Transcribe/inbox/
└── 회의/
    └── asr-multitrack/
        └── 2026-09-26/          ← 세션 폴더
            ├── alice.aac
            ├── bob.aac
            └── carol.aac
```

전사가 성공하면 인박스의 원본은 아카이브로 이동합니다. 그러니 내려받은 원본
폴더는 옮기지 말고 복사해서 넣으세요.
