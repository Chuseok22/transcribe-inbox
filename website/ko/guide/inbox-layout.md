# 인박스 폴더 구조

감시하는 폴더는 `~/Transcribe/inbox/` 하나입니다. 이 폴더 아래 어느 깊이에
파일을 두는지에 따라 카테고리와 모드가 정해집니다. 별도의 설정 파일이나 파일
이름 규칙은 쓰지 않습니다.

`~/Transcribe/inbox/`부터 센 경로 구성 요소의 개수를 보면 됩니다.

| 인박스 기준 상대 경로 | 카테고리 | 모드 | 작업 단위 |
|---|---|---|---|
| `<파일>` | `미분류` | `asr` | 그 파일 |
| `<카테고리>/<파일>` | `<카테고리>` | `asr` | 그 파일 |
| `<카테고리>/asr/<파일>` | `<카테고리>` | `asr` | 그 파일 |
| `<카테고리>/diarize/<파일>` | `<카테고리>` | `diarize` | 그 파일 |
| `<카테고리>/asr-multitrack/<세션>/<파일>` | `<카테고리>` | `asr-multitrack` | `<세션>` 폴더 전체 |

규칙을 풀어 쓰면 다음과 같습니다.

- 카테고리는 인박스 바로 아래 첫 번째 폴더의 이름입니다. 이름은 자유롭게
  정할 수 있고 `강의`, `회의`, `캡스톤`처럼 한글도 됩니다. 새 카테고리는
  폴더만 만들면 되고 따로 등록하지 않습니다.
- 카테고리 폴더 없이 인박스 루트에 파일을 두어도 처리됩니다. 이때 카테고리는
  `미분류`, 모드는 `asr`입니다. 전사 결과는
  `~/Obsidian/second-brain/Transcripts/미분류/` 아래에 저장되고, 원본은
  `~/Transcribe/archive/미분류/asr/`로 옮겨집니다.
- 모드 폴더는 두 번째 폴더이며 생략할 수 있습니다. 생략하면 `asr`입니다.
  폴더 이름은 `asr`, `asr-multitrack`, `diarize` 중 하나와 글자까지 같아야
  합니다. `ASR`처럼 대소문자가 다르거나 `multitrack`처럼 줄인 이름은 모드로
  인식하지 않습니다.
- `asr-multitrack`은 한 단계 더 깊습니다. 모드 폴더 아래에 세션 폴더를 반드시
  하나 만들고, 화자별 파일을 그 안에 바로 넣습니다. **세션 폴더**는 회의 한
  번의 화자별 파일을 묶는 폴더이며, 이름은 `2026-09-08`, `주간회의`처럼
  자유롭게 정합니다. 이 모드에서는 세션 폴더 전체가 작업 하나입니다.

위 다섯 형태에 맞지 않는 경로는 애매한 경로로 보고 건너뛴 뒤 로그만 남깁니다.
경로를 추측해서 처리하지 않습니다. 예를 들면 다음과 같은 경로입니다.

```
~/Transcribe/inbox/강의/3장/2주차.m4a                              # 두 번째 폴더가 모드 이름이 아님
~/Transcribe/inbox/회의/asr-multitrack/회의록.m4a                  # 세션 폴더 없이 파일을 바로 넣음
~/Transcribe/inbox/회의/asr-multitrack/2026-09-08/원본/김철수.m4a  # 세션 폴더 아래에 또 폴더
```

모드는 폴더 구조로만 정해집니다. "이 카테고리는 항상 diarize" 같은 기본값을
설정하는 방법은 없으며, 파일마다 놓인 경로에 따라 모드가 결정됩니다.

`~/Transcribe/archive/`(원본 보관용)를 비롯해 `~/Transcribe/inbox/` 밖의
폴더는 형제 폴더라도 감시하지 않습니다. 그래서 다운로드한 모델
(`~/Transcribe/model/` 등) 같은 다른 파일을 두어도 됩니다. 이름이 `.`으로
시작하는 숨김 파일은 위치와 관계없이 무시합니다.
