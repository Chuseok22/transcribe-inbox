# 收件箱目录结构

被监视的目标只有 `~/Transcribe/inbox/` 一处。**文件放在该文件夹下的哪一层深度**，直接决定了类别和模式 — 没有配置文件，也没有文件名规则。

只需看从 `~/Transcribe/inbox/` 起算的路径组成部分的个数：

| 相对于收件箱的路径 | 类别 | 模式 | 任务单位 |
|---|---|---|---|
| `<文件>` | `미분류`（未分类） | `asr` | 该文件 |
| `<类别>/<文件>` | `<类别>` | `asr` | 该文件 |
| `<类别>/asr/<文件>` | `<类别>` | `asr` | 该文件 |
| `<类别>/diarize/<文件>` | `<类别>` | `diarize` | 该文件 |
| `<类别>/asr-multitrack/<会话>/<文件>` | `<类别>` | `asr-multitrack` | 整个 `<会话>` 文件夹 |

用文字表述，规则共有四条：

- **类别**是收件箱正下方第一层文件夹的名称。名称可以随意取（`강의`、`회의`、`캡스톤` 等韩文名称原样可用），使用新类别时无需在任何地方登记 — 创建文件夹即可。
- **没有类别文件夹**，直接把文件扔到收件箱根目录也能正常工作，类别为 `미분류`，模式为 `asr`。转写结果会放在 `~/Obsidian/second-brain/Transcripts/미분류/` 下，原始文件则进入 `~/Transcribe/archive/미분류/asr/`。
- **模式文件夹**是第二层文件夹，可以省略。省略时为 `asr`。名称必须与 `asr`、`asr-multitrack`、`diarize` 三者之一完全一致 — 像 `ASR`、`multitrack` 这样大小写不同或变形的名称不会被识别为模式。
- 只有 `asr-multitrack` 再深一层。在模式文件夹下必须有一个**会话文件夹**，并把各说话人的文件直接放在其中。会话文件夹是**把一次会议中各说话人的文件归拢在一起的文件夹**，名称可以随意取（`2026-09-08`、`주간회의` 等）。此时任务单位不是单个文件，而是整个会话文件夹。

不属于上述五种形态的路径，一律视为**含义不明确的路径**，会被跳过并仅记录日志 — 绝不会靠猜测来处理。实际会被拦下的情形如下：

```
~/Transcribe/inbox/강의/3장/2주차.m4a                              # 두 번째 폴더가 모드 이름이 아님
~/Transcribe/inbox/회의/asr-multitrack/회의록.m4a                  # 세션 폴더 없이 파일을 바로 넣음
~/Transcribe/inbox/회의/asr-multitrack/2026-09-08/원본/김철수.m4a  # 세션 폴더 아래에 또 폴더
```

上面各行的注释依次为：第二层文件夹不是模式名称；没有会话文件夹，直接放入文件；会话文件夹下又有文件夹。

模式只由文件夹结构决定 — 没有办法设置“这个类别始终使用 diarize”这样的永久默认值，每个文件的模式都取决于该文件当时所放的文件夹路径。`~/Transcribe/archive/`（用于保存原始文件）或 `~/Transcribe/inbox/` 之外的其他文件夹，即使是同级文件夹，也绝不会被监视 — 包括已下载的模型（`~/Transcribe/model/` 等）在内，其他任何内容都可以放心地自由存放。名称以 `.` 开头的隐藏文件，无论位于何处都会被全部忽略。
