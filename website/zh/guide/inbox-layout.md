# 收件箱目录结构

被监视的文件夹只有 `~/Transcribe/inbox/` 一个。文件放在这个文件夹下的哪一层，决定了类别和模式。不使用单独的配置文件或文件名规则。

判断方法是数一数从 `~/Transcribe/inbox/` 起算的路径有几段。

| 相对于收件箱的路径 | 类别 | 模式 | 任务单位 |
|---|---|---|---|
| `<文件>` | `미분류`（未分类） | `asr` | 该文件 |
| `<类别>/<文件>` | `<类别>` | `asr` | 该文件 |
| `<类别>/asr/<文件>` | `<类别>` | `asr` | 该文件 |
| `<类别>/diarize/<文件>` | `<类别>` | `diarize` | 该文件 |
| `<类别>/asr-multitrack/<会话>/<文件>` | `<类别>` | `asr-multitrack` | 整个 `<会话>` 文件夹 |

具体规则如下。

- 类别是收件箱下第一层文件夹的名称。名称可以自由选取，`강의`、`회의`、`캡스톤` 这样的韩文名称也可以。新建类别只需创建文件夹，不用另外登记。
- 不建类别文件夹、直接把文件放在收件箱根目录也会被处理。这时类别为 `미분류`，模式为 `asr`。转写结果保存在 `~/Obsidian/second-brain/Transcripts/미분류/` 下，原文件移到 `~/Transcribe/archive/미분류/asr/`。
- 模式文件夹是第二层文件夹，可以省略，省略时为 `asr`。文件夹名称必须与 `asr`、`asr-multitrack`、`diarize` 之一逐字相同。`ASR` 这种大小写不同的名称，或 `multitrack` 这种缩写，都不会被识别为模式。
- `asr-multitrack` 多一层。模式文件夹下必须建一个会话文件夹，各说话人的文件直接放在里面。**会话文件夹**用来存放一次会议中各说话人的文件，名称可以自由选取，例如 `2026-09-08`、`주간회의`。这个模式下，整个会话文件夹是一个任务。

不符合上面五种形式的路径视为含义不明确的路径，会被跳过并记录日志。程序不会猜测路径来处理。下面这些路径属于这种情况。

```
~/Transcribe/inbox/강의/3장/2주차.m4a                              # 두 번째 폴더가 모드 이름이 아님
~/Transcribe/inbox/회의/asr-multitrack/회의록.m4a                  # 세션 폴더 없이 파일을 바로 넣음
~/Transcribe/inbox/회의/asr-multitrack/2026-09-08/원본/김철수.m4a  # 세션 폴더 아래에 또 폴더
```

各行注释依次为：第二层文件夹不是模式名称；没有会话文件夹，直接放入文件；会话文件夹下还有文件夹。

模式只由文件夹结构决定。没有办法设置“这个类别默认用 diarize”之类的默认值，每个文件的模式取决于它所在的路径。

`~/Transcribe/archive/`（存放原文件）以及 `~/Transcribe/inbox/` 之外的其他文件夹，即使是同级文件夹也不会被监视。因此可以在那里放下载的模型（如 `~/Transcribe/model/`）等其他文件。名称以 `.` 开头的隐藏文件，不论在哪里都会被忽略。
