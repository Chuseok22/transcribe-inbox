# 支持的模式

共有 3 种模式。

| 模式 | 适用场景 | 引擎 | 说话人标签 |
|---|---|---|---|
| `asr`（默认值） | 只有一位说话人的录音（讲课、自己录的备忘） | whisper.cpp | 无 |
| `asr-multitrack` | 已按说话人分成多个文件的录音（参会者各自用自己的设备录音的会议） | whisper.cpp（每条音轨运行一次） | 音轨文件名（不含扩展名） |
| `diarize` | 多位说话人混在同一个文件里的录音（用一支麦克风录制的会议） | whispermlx | 说话人分离模型添加的匿名标签 |

`asr` 和 `diarize` 的区别在于是否区分说话人，与转写质量无关。不需要区分说话人时，没有必要使用 `diarize`。它要额外运行对齐（alignment）和说话人分离步骤，耗时明显更长。

如果已经有按说话人分开的文件，`asr-multitrack` 比 `diarize` 更合适。说话人分离是推断，可能出错。`asr-multitrack` 中每个文件属于谁是确定的，说话人标签不会出错。

## `asr`：单一说话人（默认值）

省略模式文件夹即可。

```
~/Transcribe/inbox/
└── 강의/
    └── 2주차.m4a
```

- 转写结果：`~/Obsidian/second-brain/Transcripts/강의/2주차/`
- 归档：`~/Transcribe/archive/강의/asr/2주차.m4a`

像 `~/Transcribe/inbox/강의/asr/2주차.m4a` 这样写明模式文件夹，结果也一样。

## `diarize`：多位说话人在同一文件中的会议

```
~/Transcribe/inbox/
└── 회의/
    └── diarize/
        └── 2026-09-08.m4a
```

- 转写结果：`~/Obsidian/second-brain/Transcripts/회의/2026-09-08/`
- 归档：`~/Transcribe/archive/회의/diarize/2026-09-08.m4a`
- 说话人标签是说话人分离模型添加的匿名标签，不是真实姓名。谁是谁需要你对照转写稿自行确认。
- 只有这个模式需要 `HUGGINGFACE_TOKEN` 和同意模型条款（见[前置条件](/zh/getting-started/prerequisites)）。

## `asr-multitrack`：按说话人分成多个文件的会议

在模式文件夹下建一个会话文件夹，把各说话人的文件放进去。

```
~/Transcribe/inbox/
└── 회의/
    └── asr-multitrack/
        └── 2026-09-08/
            ├── 김철수.m4a
            └── 홍길동.m4a
```

- 整个会话文件夹 `2026-09-08` 是一个任务。各音轨分别转写后，按时间顺序排列，合并成一份转写稿。
- 说话人标签是文件名去掉扩展名后的部分，上例中为 `김철수` 和 `홍길동`。请用说话人的名字给文件命名。
- 转写结果：`~/Obsidian/second-brain/Transcripts/회의/2026-09-08/`（使用的是会话文件夹名称，而不是文件名）
- 归档：`~/Transcribe/archive/회의/asr-multitrack/2026-09-08/`（整个会话文件夹一起移动，不逐个移动文件）

**注意：会话文件夹中只放各说话人的音频文件。**

- 会话文件夹中除隐藏文件外的所有文件都会登记为音轨。如果混入了 `.txt`、`.dat` 这类元数据文件，程序也会尝试把它们当作音频解码，结果失败，整个会话变成 `FAILED`。失败的任务不会自动重试（见[使用方法](/zh/guide/usage)中的“失败时”）。
- 程序假定所有音轨在同一时刻开始。不支持按音轨校正起始时间（偏移量），所有音轨都从 0 秒算起，按时间顺序合并。如果各音轨开始录音的时间不同，合并后的转写稿中发言顺序可能错乱。请先确认各说话人的文件是否在同一时间开始录音。
- 文件只放在会话文件夹的下一层，不要在会话文件夹中再建子文件夹（见[收件箱目录结构](/zh/guide/inbox-layout)中的“含义不明确的路径”）。

### 示例：用 Craig 录制的 Discord 会议

在 Craig 中以多音轨方式下载的文件夹里，除了各说话人的音频，还有元数据文件。

```
craig-xxxxxxxx/
├── 1-alice.aac             # 화자별 트랙 (앞에 번호가 붙음)
├── 2-bob.aac
├── 3-carol.aac
├── info.txt               # 메타데이터 — 넣으면 안 됨
└── raw.dat                # 원본 데이터 — 넣으면 안 됨
```

上面的注释意为：各说话人的音轨（前面带编号）；`info.txt` 是元数据，`raw.dat` 是原始数据，二者都不能放入。

不要把这个文件夹整个放进去，只挑出音频文件复制到会话文件夹中。说话人标签取自文件名，所以最好去掉编号前缀（`1-alice.aac` → `alice.aac`）。

```
~/Transcribe/inbox/
└── 회의/
    └── asr-multitrack/
        └── 2026-09-26/          ← 세션 폴더
            ├── alice.aac
            ├── bob.aac
            └── carol.aac
```

`← 세션 폴더` 指会话文件夹。

转写成功后，收件箱中的原文件会移到归档。所以请复制下载的原始文件夹，不要直接移动它。
