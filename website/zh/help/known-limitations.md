# 已知限制

- whisper.cpp 尚未固定到特定的 git 标签/提交 — `brew install whisper-cpp` 会直接跟随上游的 `stable` 版本，因此在之后的升级中，行为可能会在没有任何警告的情况下发生变化。
- `diarize` 模式尚未在这台机器上针对真实录音进行过端到端测试（开发时没有安装 `whisper-cli`/模型）— 代码路径本身是在阅读了真实的 `whispermlx` 库源码之后修改的，但在真正依赖它之前，最好先做一次实机冒烟测试。
- 如果两个*不同的*录音最终得到相同的类别+标签（不是同一任务的重新运行，而是真正的文件名冲突），转写结果目录会被覆盖。原始*音频*已设计为避免这种情况（参见[输出与归档](/zh/reference/output)中说明的内容哈希后缀处理），但转写结果本身目前还没有这样的处理。
- `HUGGINGFACE_TOKEN` 目前必须直接写入（被 gitignore 的）plist 文件 — 尚不支持从 macOS 钥匙串或单独的密钥文件中获取。
- `미분류`（未分类）文件夹名称在代码中是固定的，不会随区域设置而改变。
- 转写语言目前固定为韩语（`ko`），暂不支持配置其他语言。
