# 已知限制

- whisper.cpp 还没有固定到特定的 git 标签或提交。`brew install whisper-cpp` 直接跟随上游的 `stable` 版本，所以之后升级时，行为可能在没有提示的情况下改变。
- `diarize` 模式还没有在这台机器上用真实录音做过端到端测试，开发时没有安装 `whisper-cli` 和模型。代码路径是对照真实的 `whispermlx` 库源码修改的，但依赖这个模式之前，最好先实际做一次冒烟测试。
- 两段不同的录音得到相同的类别和标签时，转写结果目录会被覆盖。这里指的是文件名确实重复，而不是同一个任务重新运行。原始音频通过[输出与归档](/zh/reference/output)中介绍的内容哈希后缀避免了这个问题，转写结果目前还没有。
- `HUGGINGFACE_TOKEN` 目前需要直接写进已被 gitignore 忽略的 plist 文件。暂不支持从 macOS 钥匙串或单独的密钥文件读取。
- `미분류`（未分类）这个文件夹名称写死在代码中，不随区域设置变化。
- 转写语言目前固定为韩语（`ko`），暂不能设置为其他语言。
